# Yamuna Plastics · TDL Code Architecture & Technical Explanation

This document explains the technical implementation of **`YamunaPlastics_Sync.tdl`**, written for Tally Prime and Tally.ERP 9.

---

## 1. System Formulas & Configuration

```tdl
[System: Formula]
    YP_DefaultAPIHost   : "http://localhost:5005"
    YP_API_ExportXML    : ##YP_DefaultAPIHost + "/api/tally/export-xml"
    YP_API_Status       : ##YP_DefaultAPIHost + "/api/tally/status"
    YP_DefaultFilePath  : "C:\Users\admin\Downloads\Projects\Yamuna Plastics\tdl\YamunaPlastics_Import.xml"
```

### Explanation:
- **`YP_DefaultAPIHost`**: Defines the base URL of the Yamuna Plastics REST API. Can be changed to a LAN IP (e.g. `http://192.168.1.50:5005`) if Tally is running on a different computer than the mobile server.
- **`YP_API_ExportXML`**: Endpoint returning pure Tally XML `<ENVELOPE>` containing all pending sales vouchers.
- **`YP_DefaultFilePath`**: Default fallback location for offline XML file imports.

## 2. Gateway of Tally Menu Modification

```tdl
[#Menu: Gateway of Tally]
    Add: Key Item: Before: @@locQuit : "Yamuna Plastics Mobile Sync" : Y : Menu : YP_MainMenu
```

### Explanation:
- The `#` prefix in `[#Menu: Gateway of Tally]` indicates modification of Tally's core Gateway menu without overwriting existing options.
- `Add: Key Item: Before: @@locQuit`: Places the new menu item right before the **Quit** command.
- `"Yamuna Plastics Mobile Sync" : Y`: Displays the menu title and binds the hotkey **`Y`** for quick keyboard access.
- `: Menu : YP_MainMenu`: Specifies that pressing this item navigates to our custom sub-menu `YP_MainMenu`.

## 3. Sub-Menu Definition

```tdl
[Menu: YP_MainMenu]
    Title   : "Yamuna Plastics - Mobile Billing & TDL Sync Center"
    Indent  : "Yamuna Plastics"

    Key Item: "Sync All Pending Bills from Mobile App" : S : Call    : YP_Fn_SyncFromMobileAPI
    Key Item: "Import Local XML File"                  : I : Call    : YP_Fn_ImportLocalXMLFile
    Key Item: "Yamuna Plastics Sync Dashboard"         : D : Display : YP_SyncDashboardReport
    Key Item: "Configure API Server Settings"          : C : Modify  : YP_ConfigReport
    Key Item: "Open Sales Register"                    : V : Display : Sales Register
```

### Explanation:
- Defines the 5 key operational commands:
  - **`S`**: Calls the TDL procedural function `YP_Fn_SyncFromMobileAPI` to sync via HTTP.
  - **`I`**: Calls `YP_Fn_ImportLocalXMLFile` to import from disk.
  - **`D`**: Opens the custom TDL dashboard report `YP_SyncDashboardReport`.
  - **`C`**: Opens the configuration screen to edit server IPs.
  - **`V`**: Opens Tally's built-in **Sales Register** so the accountant can immediately review imported sales vouchers.

## 4. The Sync Function (`[Function: YP_Fn_SyncFromMobileAPI]`)

```tdl
[Function: YP_Fn_SyncFromMobileAPI]
    Variable: vApiUrl      : String
    Variable: vXmlPayload  : String
    Variable: vSuccessMsg  : String

    01 : Set : vApiUrl : @@YP_API_ExportXML
    02 : Msg Box : "Yamuna Plastics Sync" : "Connecting to Mobile App API server at " + ##vApiUrl + "..."
    03 : Trigger : Import File : ##vApiUrl : "XML" : "Transactions"
    04 : Set : vSuccessMsg : "Sync Completed successfully! All pending bills from Yamuna Plastics Mobile App have been posted to your Sales Vouchers."
    05 : Msg Box : "Yamuna Plastics - Success" : ##vSuccessMsg
    06 : Display : Day Book
    07 : Return
```

### Explanation:
- Line 01: Sets `vApiUrl` to the REST API export URL (`http://localhost:5005/api/tally/export-xml`).
- Line 02: Displays an informational message box informing the user that the connection is starting.
- Line 03: `Trigger : Import File : ##vApiUrl : "XML" : "Transactions"`:
  This is Tally's core internal action to parse an incoming XML transaction envelope over HTTP and insert the vouchers directly into the company's ledger and inventory registers.
- Line 05: Notifies the user upon completion.
- Line 06: Immediately displays the **Day Book** screen so the accountant can inspect the newly created transactions.

## 5. Dashboard Report & Screen Definition

```tdl
[Report: YP_SyncDashboardReport]
    Title       : "Yamuna Plastics - Mobile Sync Dashboard"
    Form        : YP_SyncDashboardForm

[Form: YP_SyncDashboardForm]
    Part        : YP_DashboardTitlePart, YP_DashboardInfoPart, YP_DashboardActionPart

```

### Explanation:
- Custom report that presents a dedicated control panel inside Tally Prime with F6/F7 shortcut buttons:
  - **`F6: Sync API`** -> Executes `YP_Fn_SyncFromMobileAPI`.
  - **`F7: Import File`** -> Executes `YP_Fn_ImportLocalXMLFile`.

## 6. XML Schema Compatibility

The XML generated by the backend API and imported by this TDL adheres strictly to the official Tally Definition Language XML schema:

1. **Voucher Type**: `<VOUCHER VCHTYPE="Sales" ACTION="Create">`
2. **Bill Reference**: `<BILLALLOCATIONS.LIST><NAME>YP/26-27/101</NAME><BILLTYPE>New Ref</BILLTYPE></BILLALLOCATIONS.LIST>`
3. **Inventory Allocations**:
   ```xml
   <ALLINVENTORYENTRIES.LIST>
     <STOCKITEMNAME>HDPE Plain Liner Bags (50 Micron)</STOCKITEMNAME>
     <RATE>132.00/KGS</RATE>
     <ACTUALQTY> 500.00 KGS</ACTUALQTY>
     <BILLEDQTY> 500.00 KGS</BILLEDQTY>
     <AMOUNT>66000.00</AMOUNT>
   </ALLINVENTORYENTRIES.LIST>
   ```
4. **GST Accounting**:
   - `Output CGST 9%` & `Output SGST 9%` for intra-state (Gujarat).
   - `Output IGST 18%` for inter-state (e.g. Rajasthan, Maharashtra).
5. **Debtor Allocation**: Debits the buyer ledger with `-Amount` matching standard double-entry principles.
